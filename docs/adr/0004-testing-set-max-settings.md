# Testing set max is Settings-only; first-run stays at three

The recommended Testing set size is three. First-run selection hard-caps at three so onboarding stays simple. After first-run, Settings may store an integer max (default 3, floor 1, ceiling = current App-visible count), including “Add all App-visible,” with a persistent recommendation and a confirm only when crossing above three. Auto-following new App installs was rejected so the Testing set stays an explicit choice, distinct from the install list.
